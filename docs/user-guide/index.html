Запись работающего интерфейса

Видеодемонстрация

Кнопки подсвечены рамкой, действия поясняются титрами. Выберите главу, чтобы перейти к нужной функции. Звуковой дорожки нет.

01
Первый запуск

Установить и подключить

Расширение работает в Chrome и добавляет рабочую область в MaxPatrol VM. Инструкция подготовлена для версии расширения 1.2.0 и интерфейса MaxPatrol VM 28.0.

  1. Распакуйте расширение. Откройте chrome://extensions, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите папку vm_remediation с manifest.json.
  2. Нажмите иконку расширения. Укажите сервер, при необходимости порт и персональный токен из PT MC → «Токены доступа». Пустой порт означает порт открытой страницы MaxPatrol.
  3. Нажмите «Сохранить», затем «Проверить подключение». Откройте или обновите вкладку MaxPatrol VM: в меню появится «Устранение».
После обновления файлов сначала перезагрузите расширение на chrome://extensions, затем саму вкладку MaxPatrol. Права операций определяются владельцем токена.
02
Навигация

Открыть рабочую область

Выбирайте раздел по задаче: оценить ситуацию, назначить обновление, разобраться с CVE или подготовить отчёт.

  1. Нажмите «Устранение» в левом меню MaxPatrol. Переключайтесь между вкладками в верхней строке.
  2. Если показан сохранённый снимок, посмотрите его дату. Данные обновляются кнопкой текущего раздела: «Обновить показатели», «Построить очередь», «Рассчитать» и т. п.
  3. HTML, PDF и CSV справа в шапке относятся к активному разделу. Пока данные не загружены, соответствующие кнопки недоступны.
Снимки сохраняются локально на сутки. Повторное открытие раздела не означает, что данные уже перечитаны с сервера. Крестик справа закрывает рабочую область.
03
Обзор

Оценить состояние процесса

Начинайте ежедневную работу с обзора: он показывает объём открытых уязвимостей, просрочки и важные сигналы.

  1. Откройте «Обзор» и нажмите «Обновить показатели».
  2. Посмотрите открытые, просроченные и истекающие уязвимости. Ниже находятся распределения по опасности и возрасту, трендовые CVE и узлы с высокой оценкой.
  3. При необходимости включите «История за 30 дней» и обновите показатели. Для руководства используйте «Отчёт для руководства», «Скачать HTML» или «Печать / PDF». JSON сохраняет исходные показатели.
Пороговые сроки задаются в «Настройках». Исторический срез может загружаться дольше обычного обзора; учитывайте объём данных вашей системы.
04
Показатели и таблицы

Перейти от числа к выборке

Показатели обзора кликабельны: за числом можно увидеть конкретные уязвимости и активы.

  1. Нажмите показатель, например «просрочено по SLA», или число в таблице уровня опасности.
  2. Изучите CVE, узел, статус и дату. Ссылка на CVE ведёт к паспорту, ссылка на узел — к карточке актива.
  3. Используйте CSV выборки, копирование PDQL, переход в список активов MaxPatrol или «В проект». Закройте выборку крестиком, когда закончите.
В таблицах работают текстовый поиск, сортировка по заголовку и фильтр значений по значку рядом с ним. Активные фильтры можно сбросить; правый клик по ячейке оставляет её значение.
05
Очередь устранения

Построить очередь обновлений

Очередь помогает перейти от отдельных CVE к конкретным работам по обновлению ПО, пакетов или ОС.

  1. Выберите источник: «ПО на узлах», «Пакеты Unix» или «Операционные системы». Задайте минимальный CVSS и число групп.
  2. Нажмите «Построить очередь». При необходимости используйте фильтры «трендовые», «эксплойт», «critical», «есть патч» и поиск в таблице.
  3. Нажмите строку нужного продукта и версии. Флажок «свернуть по продукту» позволяет сначала рассмотреть продукт в целом.
Группы отсортированы по устраняемому риску. CVSS и лимит групп влияют на запрос; фильтры отображения помогают просматривать уже загруженные результаты.
06
Детали очереди

Назначить работу по группе

В деталях группы собраны экземпляры, узлы и CVE с внешними сигналами.

  1. Проверьте название и версию продукта, число экземпляров и список узлов. «CSV узлов» выгружает отдельную таблицу активов.
  2. Нажмите «В проект» и введите название: экземпляры получат метку proj:название. Для Jira сначала можно нажать «Найти существующие».
  3. Выберите статус: «В работе», «Исправляется до даты», «Исключить» или «Вернуть в Новая». Для соответствующих операций задайте дату или причину, добавьте комментарий и нажмите «Применить в MaxPatrol VM».
Смена статуса применяется ко всем загруженным экземплярам группы и требует подтверждения. Успешная смена статуса не устанавливает обновление на узлы.
07
Патчи

Выбрать патч для установки

Во вкладке «Патчи» открытые уязвимости сгруппированы по исправлению из паспорта MaxPatrol.

  1. Откройте «Патчи» и загрузите список кнопкой построения. Сравните число уязвимостей, узлы и признаки опасности.
  2. Нажмите строку обновления. В деталях проверьте узлы, CVE и ссылку вендора на патч.
  3. Из выбранного патча можно создать задачу Jira, добавить экземпляры в проект, сменить их статус или выгрузить CSV.
Строка исправлений без названия и ссылки учитывается в сводке отдельно. Само расширение не устанавливает патчи; установку выполняют штатные средства вашей инфраструктуры.

08
Интеграция

Подключить Jira и создать задачу

Jira связывает выбранную работу с экземплярами уязвимостей в MaxPatrol.

  1. В «Настройках» заполните блок Jira. Для Cloud выберите email + API token, для Server / DC — персональный токен. Укажите проект и тип задачи.
  2. Нажмите «Сохранить Jira» и «Проверить подключение». Кнопка «Список проектов» помогает проверить доступные проекты.
  3. Откройте группу очереди, патч, выбранный экземпляр CVE или карточку актива и нажмите кнопку создания задачи. Дождитесь ссылки на задачу и результата операции.
Если включена опция меток, на экземпляры ставится jira:KEY. Масштаб задачи зависит от места запуска: группа ПО, патч, один экземпляр или узел. Создание на демонстрационном стенде имитируется.

09
Риск активов

Сравнить риск активов

Оценка 0–1000 помогает выбрать узлы для первоочередной работы.

  1. Откройте «Риск активов» и нажмите «Рассчитать». Посмотрите зоны риска и сводки по группам активов.
  2. Ниже изучите «Топ активов по риску». Фильтруйте по значимости; наведите указатель на оценку и столбики компонентов, чтобы увидеть причины.
  3. При необходимости нажмите «Уточнить по KEV». Ссылка «уязвимости» открывает выборку узла; «Теги зон риска» назначает активам соответствующие auto:risk-* теги.
Модель объединяет экспозицию, опасность CVSS, угрозу и компонент критичности с поправкой на контекст. Веса настраиваются. Значение риска — показатель этой модели, а не число уязвимостей.

10
Исключения

Пересмотреть исключения

Реестр помогает проверить, не остались ли за пределами работ опасные уязвимости.

  1. Нажмите «Загрузить реестр». Сравните причины, наличие комментариев и признаки опасности.
  2. В блоке «Сомнительные исключения» найдите трендовые уязвимости, экземпляры с эксплойтом или CVSS от 9.
  3. Если решение об исключении нужно отменить, нажмите «Вернуть в работу» и подтвердите операцию для указанного числа экземпляров.
«Вернуть в работу» переводит экземпляры группы в статус «Новая». Если реестр ограничен лимитом, это отмечено в интерфейсе и отчёте; экспорт не догружает остальные записи.
11
Проекты

Отслеживать прогресс проекта

Проект объединяет уязвимости меткой и показывает результат работ по текущим данным MaxPatrol.

  1. Создайте проект кнопкой «В проект» из группы или выборки либо используйте метку связанной задачи Jira.
  2. Откройте «Проекты», при необходимости задайте префикс метки и нажмите «Обновить».
  3. Нажмите строку проекта, чтобы увидеть его уязвимости и узлы. Кнопка «Закрыть» снимает метку проекта с экземпляров.
Прогресс = (устранённые + исключённые) / все экземпляры. Поэтому 100% не обязательно означает, что все уязвимости исправлены. «Закрыть» не устраняет уязвимости и не закрывает задачу Jira.
12
Контейнеры и веб

Проверить контейнерные образы

Образы рассматриваются отдельно от установленного на узлах ПО.

  1. Нажмите «Образы: сводка», чтобы сравнить наборы образов по количеству и опасности уязвимостей.
  2. Нажмите «Образы: очередь по пакетам», чтобы перейти к пакету и версии внутри образа.
  3. Откройте строку пакета: появятся CVE и затронутые наборы образов. Планируйте обновление базового образа или пакета в процессе сборки.
Показатели относятся к загруженным данным инвентаризации образов. Для отчёта по нужному представлению сначала откройте и загрузите именно его.
13
Контейнеры и веб

Посмотреть уязвимости веб-сайтов

В этом же разделе можно просмотреть результаты веб-аудита.

  1. Нажмите «Веб-сайты». В сводке сравните число открытых уязвимостей, critical, high и максимальный CVSS.
  2. В таблице ниже используйте поиск по сайту, названию или CVE. Ссылка на уязвимость ведёт к паспорту.
  3. Нажмите HTML, PDF или CSV, чтобы сохранить загруженные сведения этого представления.
Наличие данных зависит от веб-сканирования и доступных активов типа WebSite. Пустая таблица сама по себе не доказывает отсутствие уязвимостей на всех сайтах организации.
14
Инвентаризация

Разметить активы тегами

Правила назначают активам auto:* теги по условиям PDQL.

  1. Просмотрите группы правил и оставьте отмеченными нужные. Нажмите «Применить отмеченные» и проверьте результаты по каждому правилу.
  2. Используйте «Покрытие тегами» и «Список тегов», чтобы посмотреть назначенные метки.
  3. Для собственного правила укажите имя тега и PDQL с select(@Host), затем нажмите «Добавить и применить».
Правила угроз и сроков стоит повторять после сканирования. Старые теги не снимаются автоматически. «Удалить все auto:*» удаляет все теги с таким префиксом; заранее проверьте, какие метки будут затронуты.

15
CVE-контекст

Загрузить внешние сведения по CVE

Обогащение объединяет внешние сигналы с экземплярами уязвимости в MaxPatrol.

  1. Вставьте список CVE или произвольный текст. Можно нажать «Найти CVE на открытой странице MaxPatrol».
  2. Нажмите «Обогатить». Для полного контекста не включайте «без NVD» и «без экземпляров MP VM»; источники также должны быть включены в настройках.
  3. Сравните приоритет, причины и срок. Кнопка «PoC на GitHub?» отдельно загружает результаты поиска; БДУ появляется после импорта выгрузки.
Отсутствующий ответ источника не равен отсутствию риска. Данные внешних сервисов на скриншотах — демонстрационный снимок; использовать их как актуальную оценку конкретных CVE нельзя.
16
CVE-контекст

Выбрать экземпляр на нужном узле

Одна CVE может присутствовать на нескольких узлах с разными условиями устранения.

  1. В блоке «В MaxPatrol VM» откройте список «Экземпляр на активе» и выберите нужный узел.
  2. Проверьте ОС, текущую версию, требуемую и рекомендуемую версии, патч и срок SLA. Перейдите в карточку экземпляра или паспорт для подробностей.
  3. При необходимости создайте «Задачу в Jira» на выбранный экземпляр или переведите его «В работу». Дождитесь окончания загрузки перед экспортом.
При открытии из карточки экземпляра или актива выбор может определиться по текущему адресу страницы. В общий отчёт включаются список экземпляров и подробности выбранного экземпляра; другие карточки не догружаются экспортом.
17
Дополнения MaxPatrol

Работать из штатных карточек

Часть функций доступна без открытия общей рабочей области «Устранение».

  1. В карточке или паспорте уязвимости найдите блок «Внешний контекст» и нажмите «EPSS, KEV, SSVC и ссылки на патчи».
  2. В карточке конкретного экземпляра доступна задача Jira на этот экземпляр. В карточке актива есть «Выгрузить уязвимости в CSV» и «Задача в Jira» по узлу.
  3. CSV актива включает уязвимости во всех статусах и сообщает о достижении лимита 50 000 строк.
На этих двух иллюстрациях оболочка карточек MaxPatrol имитирована; добавленные расширением блоки сняты с работающего кода. В вашей версии продукта окружающая разметка может отличаться.

18
Настройки

Настроить источники и сроки

Общие настройки определяют состав обогащения и расчёт показателей.

  1. Включите нужные источники EPSS, CISA KEV, NVD и GitHub. При необходимости введите ключи сервисов; каталог KEV можно обновить отдельной кнопкой.
  2. Проверьте сроки critical / high / medium / low и веса модели риска. Для БДУ выберите выгрузку XML, CSV, TXT или TSV через «Загрузить файл БДУ».
  3. Нажмите «Сохранить настройки», затем заново обновите соответствующий раздел. Параметры подключения к MaxPatrol находятся в окне иконки расширения, а Jira сохраняется отдельной кнопкой.
Нормы сроков и модель риска нужно согласовать с вашим процессом. Настройка переходов позволяет открывать ссылки дашборда в текущей вкладке; Ctrl/Cmd + клик сохраняет открытие в новой.
19
Экспорт

Подготовить полный HTML-отчёт

HTML удобен для передачи подробного отчёта: файл можно открыть в браузере без установленного расширения.

  1. Обновите нужный раздел, откройте необходимую детализацию и дождитесь обогащения. В CVE-контексте выберите экземпляр; при необходимости загрузите GitHub.
  2. Нажмите HTML в шапке. Откройте скачанный файл: сводка останется на виду, а подробности будут свёрнуты.
  3. Раскрывайте заголовки CVE и источников по отдельности либо используйте «Раскрыть всё» и «Свернуть всё». Заголовки также доступны с клавиатуры через Enter и пробел.
Отчёт содержит все загруженные данные текущего раздела и открытую детализацию. Поиск и фильтры таблиц не сокращают экспорт. Новые сведения с сервера экспорт не запрашивает; предупреждение о лимите означает, что часть данных ещё не загружена.

Экспорт

Выбрать PDF или CSV

Выбирайте формат по дальнейшему использованию отчёта.

  1. PDF: нажмите PDF в шапке раздела или «Печать / PDF» в обзоре. В диалоге печати браузера выберите «Сохранить как PDF».
  2. При печати скачанного HTML все разделы автоматически раскрываются; после завершения печати прежнее состояние спойлеров восстанавливается. PDF содержит полный отчёт и может оставаться многостраничным.
  3. Общий CSV и CSV-вложения Jira имеют колонки «Раздел;Запись;Поле;Значение» в UTF-8 с BOM. «CSV узлов», CSV отдельной выборки и CSV карточки актива сохраняют обычные колонки таблицы.
Спойлеры упрощают просмотр HTML, но не удаляют данные и не уменьшают число страниц полного PDF. Для табличного анализа открывайте CSV с разделителем «точка с запятой».

Если что-то не работает

Не появился пункт «Устранение»

Проверьте, что расширение включено, сервер и токен сохранены, открыта нужная вкладка MaxPatrol. После обновления расширения перезагрузите вкладку продукта. Проверьте подключение через иконку расширения.

Ошибка подключения или доступа

Сверьте адрес, порт, доступность сервера и срок действия токена. У владельца токена должны быть права на нужные данные и операции. Если проверка предлагает перезагрузить вкладку сервера, выполните это действие.

В отчёте не хватает обогащения

Убедитесь, что источник включён и ответ получен. Откройте детали группы или патча; для CVE выберите экземпляр, загрузите GitHub при необходимости. После этого сформируйте новый отчёт. Посмотрите ошибки источников и предупреждение о лимите.

В CSV больше строк, чем видно на экране

Это ожидаемо: поиск, фильтры таблицы и ограничение отображения не обрезают общий экспорт. Для таблицы конкретных узлов используйте «CSV узлов»; для выбранного показателя — CSV его выборки.

В PDF нет спойлеров

PDF предназначен для полного статичного отчёта. Все загруженные разделы печатаются раскрытыми; для компактного интерактивного просмотра используйте HTML.

Не создаётся задача Jira

Проверьте сохранённые настройки Jira, подключение, проект и тип задачи. Прочитайте сообщение операции. Перед повтором проверьте, не создана ли задача уже: в группе очереди доступен поиск существующих.

Показатели не изменились после работы

Сравните дату снимка и обновите нужный раздел. Для подтверждения фактического устранения нужны актуальные результаты сканирования; назначение статуса или создание задачи сами по себе не устанавливают патч.
