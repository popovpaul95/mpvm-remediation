# Руководство пользователя

Откройте index.html в браузере. PDF находится в guide.pdf, видео — в demo.mp4.

- 25 скриншотов с увеличением по нажатию.
- 21 глава видеодемонстрации, 3:16, русские титры без озвучки.
- Пример сворачиваемого отчёта — example-report.html.
- Таймкоды — chapters.txt; отдельные субтитры — captions.vtt.

Для переноса сохраняйте всю папку целиком. Данные демонстрационные: код расширения настоящий, оболочка MaxPatrol и ответы сервисов имитируются. Действующие токены не используются.

Версия расширения 1.2.0, MaxPatrol VM 28.0. Подготовлено 29.09.2026.
