Второй дефект на реальном 27.6: блок «Внешний контекст» не появлялся в карточке экземпляра. Причина: в 27.6 карточка отрисовывается внутри shadow root (`ips-shell-remote-app`), а `MutationObserver` за `document.body` изменений внутри shadow DOM не видит. Регрессионный сценарий «Интерфейс 27.x: блок в карточке экземпляра внутри shadow DOM» (карточка вставляется в shadow root после загрузки cards.js без изменений light DOM, идентификатор экземпляра читается из hash, блок не дублируется); без исправления сценарий падает.
